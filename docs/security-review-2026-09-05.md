# Release-readiness security review

This is a targeted source review and regression-test record for installation, harness execution, MCP permissions and imported archives. It is not an exhaustive certification of every dependency, operating system or agent application.

## Corrected boundaries

- **Step-scoped MCP authorization:** a server started with `--context` previously registered unrestricted authoring tools after its scoped tools. A step could call `run_workflow` and bypass its workflow allowlist/nesting checks, or read unrelated journal records. Scoped servers now return only their native step tools. Regression tests enumerate the exact tool list and try the forbidden endpoint.
- **Bundle install/remove paths:** names `.` and `..` could resolve to a parent/library directory before recursive replacement. Portable name validation rejects dot segments, Windows device names, alternate streams and ambiguous paths. Every install/remove/unpack destination is checked for containment and existing symlinks/junctions.
- **Imported run and artifact paths:** imported run IDs and artifact metadata could escape their intended directory, including reading unrelated files on a later export. IDs and artifact paths are validated before journal mutations and rechecked during export. Runtime artifact selection is restricted to files under the task directory; model-produced output cannot make Flora copy a file from outside it.
- **Archive expansion:** archive size, entry count and decompressed sizes are bounded. Inflation itself is capped, including when a ZIP lies about its expected size. Duplicate/ambiguous names and files outside the manifest inventory are rejected. Checksums detect corruption; they are not a publisher signature or a reason to trust workflow commands.
- **CLI process boundary:** Windows explicit `.cmd` paths and child PATH are resolved consistently. npm JavaScript shims bypass shell interpolation. Ordinary batch files reject multiline arguments. Already cancelled work never starts a child. Codex prompt operands are separated from flags; truncated JSON streams fail instead of looking successful.
- **Ambient MCP configuration:** Claude runs with strict MCP settings even with no declared servers. Codex's empty-table override was experimentally confirmed to merge with personal config. Flora enumerates effective servers, disables them explicitly, and mounts the contract's servers under fresh names to avoid inheriting personal environment settings. These are tool-configuration boundaries, not an OS sandbox against arbitrary shell execution.
- **External worker protocol:** local SQLite updates make claiming exclusive across connections; random capability tokens authorize heartbeat/completion, never appear in listings and are removed on completion. Expired/cancelled/duplicate replies fail. The engine verifies the result independently. Routing labels do not authenticate applications; the local OS user and configured MCP clients share the queue trust boundary.

## Verification and remaining boundaries

Regression tests cover the corrected behaviors, including a single stdio client starting an external workflow, claiming work, supplying a real artifact, completing it and observing independent verification. Installation smoke tests use bundled Node with global Node removed from PATH and a working directory containing spaces and Cyrillic characters. Dependency audit of production packages reported zero known advisories at review time.

Workflow YAML, explicitly supplied shell commands, provider configuration and the configured local OS user remain trusted. A workflow may intentionally run code; importing/inspecting a bundle is not authorization to execute its commands. The external route does not promise tool isolation inside another application's existing session and rejects per-step tool mounting. Publisher signing is not configured. Live model success requires usable local harness credentials; the inspected host's Codex CLI had a config parse error and Claude CLI was logged out, so model execution was not represented as validated.
