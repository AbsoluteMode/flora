# Как флору ставит человек со стороны

> Дополнено решением [2026-09-06](2026-09-06-npm-only-cli-only.md): нативные установщики, появившиеся после
> этой записи, убраны; канал снова один — npm-пакет.

## Контекст

Первый прогон конвейера уехал коллеге файлом `.flora-run`, и к нему пришлось писать инструкцию с
установкой. Она упиралась в `npm install -g github:AbsoluteMode/flora` — команда, которая у человека
со стороны не работает: репозиторий приватный. Запасной путь в инструкции звучал как «попроси файл
`flora-0.1.0.tgz`». Своей машине это тоже стоило времени: глобальная `flora` была `npm link` на рабочее
дерево, отставшее на сорок коммитов, и по выводу `flora --version` это было никак не видно.

## Решение

npm — основной канал, тарбол на GitHub Release — запасной. Пакет называется `@absolutemode/flora`
(имя `flora` в реестре занято чужим пакетом — «FLexible Open Rest API»), ставится как
`npm install -g @absolutemode/flora`, бинарь остаётся `flora`. Релиз делает тег `v*`:
`.github/workflows/release.yml` гоняет типы и тесты, сверяет тег с `package.json`, публикует с
`--provenance` и вешает тот же тарбол на релиз.

К этому три вещи, без которых установка остаётся недоделанной:

- `bin/flora.mjs` проверяет версию Node **до** импорта кода: на Node ниже 22.5 человек получает три
  строки про `node:sqlite` и ссылку на nodejs.org вместо стектрейса из глубины модульного графа;
- `flora doctor` первой строкой печатает версию и каталог, откуда флора запущена, и говорит вслух,
  когда это чекаут, а не установленный релиз;
- `README` больше не отправляет новичка в `examples/` — их нет в его рабочем каталоге после
  глобальной установки. Вместо этого в quickstart лежит контракт на восемь строк, который можно
  сохранить и запустить.

## Почему

Канал должен закрывать Windows: конвейер, ради которого всё затевалось, гоняется с путями вида
`E:\work projects\…`. Homebrew это не закрывает, а раздача тарбола руками — не канал, а переписка.
npm ставится там, где уже стоит Node, а Node флоре нужен в любом случае.

Скоуп вместо короткого имени — потому что `npm install -g flora` сегодня ставит чужой пакет. Это не
только неудобство: человек по нашей же инструкции получит не то, что мы имели в виду.

## Что протестировали

- **Выпил `tsx` из рантайма** (собрать `dist/` и не тащить транспайлер) — гипотеза не подтвердилась
  цифрами. Старт CLI и так 130 мс: у tsx есть кеш транспиляции. Вес: tsx 668 КБ против zod 7.7 МБ и
  MCP SDK 5.9 МБ — экономия теряется на фоне зависимостей. Цена была бы высокой: 206 относительных
  импортов написаны без расширений (`moduleResolution: bundler`), то есть либо переписывать их все под
  Node ESM, либо бандлить — а бандл сплющивает структуру и ломает четыре места, где код находит свои
  файлы через `import.meta.url` (`bin/`, `web/`, `schema/`, `package.json`).
- **`tsc → dist/` с зеркальной структурой** — пути `import.meta.url` при этом как раз выживают
  (`src/web/server.ts` и `dist/web/server.js` лежат на одной глубине), но упирается в те же 206
  импортов без расширений.
- **Определять `npm link` сравнением путей** — не работает: Node разрешает симлинки в
  `import.meta.url`, и связанный пакет сам сообщает путь чекаута. Признак — наличие `.git` в корне
  пакета: в опубликованном тарболе его нет.
- **Сборка и установка тарбола в отдельный префикс** — `--version`, `doctor` и прогон контракта
  работают, тесты в пакет не попадают, 68 файлов, 134 КБ.
- **Пороги проверки Node** — 18.20.4 / 20.11.0 / 22.4.1 отказ, 22.5.0 / 22.19.0 / 24.11.1 проходят.
- **Контракт из README** прогнан целиком: первый вариант в черновике был неверным (`checks:` и
  `executor: { command: true }` вместо `verify:` и `harness: command`).

## Отвергли

- **Homebrew tap** — приятно на маке, но не закрывает Windows и добавляет второй канал на поддержку.
- **Автономный бинарь (Node SEA)** — `node:sqlite` и tsx делают сборку дорогой, ~60–100 МБ на
  платформу и три пайплайна вместо одного; Node у аудитории и так есть.
- **Только тарбол на релизе** — пока репозиторий приватный, ссылка требует токена, то есть это снова
  «пришли файл»; остаётся как запасной путь, не как основной.
