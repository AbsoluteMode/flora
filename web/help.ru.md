# Как читать результаты в Flora

**Конвейер** — последовательность задач. **Прогон** — одно выполнение конвейера. Готовый файл результата позволяет посмотреть, что получилось, без повторного обращения к модели.

## Куда нажимать

1. Сначала посмотрите статус. **Passed** — заданные проверки прошли. **Failed** или **Interrupted** — полный результат ещё не готов.
2. Нажмите этап на схеме или кнопку **Inspect** в его карточке.
3. **Input** — данные на входе. **Output** — сохранённый результат. Нажмите строку таблицы: **Record** покажет запись отдельной читаемой карточкой. **Table** вернёт таблицу. **JSON** нужен для технического разбора.
4. Чтобы понять ответ модели, откройте **Calls** и выберите запрос. Рядом будут исходные данные, промпт (**Prompt**) и ответ (**Output**). Ответ, целиком состоящий из блока JSON, тоже можно читать карточкой; **Original** показывает точный исходный текст. Кнопка **View failed requests** показывает только запросы с ошибками.
5. **Files** — сохранённые документы и таблицы. **Checks** — проверки результата. **Read report** на странице прогона открывает его отчёт.

Flora показывает то, что сохранил конвейер. Отсутствующие исходные данные или ответы восстановить из итоговых цифр нельзя. Статус Passed подтверждает заданные проверки; содержательные выводы по-прежнему оценивает аналитик.

## Открыть присланный результат

После первоначальной установки Flora откройте терминал в папке с присланным файлом и выполните:

```text
flora open "result.flora-run"
```

Замените result.flora-run на имя полученного файла. Откроется браузер. Терминал оставьте открытым, пока читаете результат. Для просмотра готового файла подписка на модель не нужна; новые запросы к модели не выполняются.

На Windows: откройте папку с файлом, нажмите её адресную строку, введите **powershell** и нажмите Enter. Затем вставьте команду выше. На macOS или Linux используйте приложение «Терминал»; коллега может дать команду с полным путём к файлу, чтобы не переходить между папками.

## Получить новый результат

Для нового запуска нужен другой файл — **.flora**. Файл **.flora-run** содержит уже полученный результат. Автор конвейера должен приложить короткую команду запуска и указать, какой исполнитель нужен: например, Claude CLI с входом по вашей подписке.

Сейчас интерфейс Flora предназначен для просмотра: кнопки запуска нового конвейера и формы выбора входных данных в нём ещё нет. Первоначальную установку и команду запуска нужно подготовить отдельно. Для чтения результатов редактировать код, JSON или промпты не требуется.

Если прогон остановился, откройте проблемный запрос и передайте автору конвейера его номер и сообщение об ошибке. Частичные результаты можно изучать, но это ещё не завершённое исследование.
